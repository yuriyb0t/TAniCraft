## P1 — заметные дефекты

### T-028 · Duplicate Layer ломает счётчик `next_uid` (коллизия UID)
**Файлы:** `src/app.rs` (`Cmd::DuplicateLayer`, `doc_fresh_uid`), `src/doc.rs`
(`Document::next_uid`, `take_uid`)
**Симптом:** `DuplicateLayer` назначает новому слою `uid = max(uid)+1` через
`doc_fresh_uid()`, но приватный счётчик `Document::next_uid` не двигается. Следующий
`New Layer` (`add_layer`) выдаёт тот же uid, который уже занят дубликатом. Два слоя
с одинаковым uid ломают кэш текстур (ключ `(uid, frame)`), undo (`layer_uid`) и
`layer_index()` — визуально это «чужой» рисунок/залипание текстур после undo.
**Критерий:** uid выделяется единым аллокатором `Document` (публичный
`Document::take_uid`), `next_uid` монотонен, тест: duplicate → new layer → оба
`layer_index(uid)` различны, uid уникальны.

### T-015 · Кэш `blank_cache` не чистится
**Файлы:** `src/app.rs` (`blank_cache`), `src/timeline.rs`
**Симптом:** записи копятся при удалении слоёв/кадров (утечка памяти на больших
проектах). Строка `self.blank_cache.retain(|_, (rev, _)| *rev > 0)` в `timeline.rs`
— фактический no-op: `rev` всегда ≥ 1, поэтому не удаляется ни одна запись. Из-за
сдвига индексов кадров при вставке/удалении устаревшая запись `(uid, frame)` может
совпасть с другим кадром и выдать неверный `is_blank`.
**Критерий:** при удалении слоя/документа/undo-структуры кэш очищается или
фильтруется по существующим `(uid, frame)`; тест: после удаления кадра/слоя запись
уходит.

### T-029 · Мутации вне undo
**Файлы:** `src/timeline.rs` (fps в тулбаре, переключатели eye/lock),
`src/app.rs` (`properties_content`: имя/visible/locked слоя)
**Симптом:** изменение fps, имени слоя, видимости и блокировки пишет в `doc` и
ставит `dirty = true` напрямую, без `commit()`. Ctrl+Z не откатывает эти правки —
нарушается инвариант «каждая мутация участвует в undo» (AGENTS.md).
**Критерий:** перечисленные мутации проходят через `commit(before)` (структурный
снимок) либо осознанно вынесены за undo с комментарием в коде; Ctrl+Z откатывает их.

### T-026 · Мультивыделение кадров
**Идея:** drag-рамка по сетке, `Shift`/`Ctrl`, групповые F5/F6/удаление. Требует
переработать `sel_frame` в `selection: (layer, RangeInclusive<usize>)`.

### T-027 · Превью в диалоге открытия
**Идея:** показывать первый кадр/размер/fps проекта до открытия.

### T-030 · Экспорт WebM: проверить `yuva420p`
**Файлы:** `src/export.rs`
**Проверка:** для WebM задаётся `-pix_fmt yuva420p` с кодеком `libvpx-vp9`. VP9
может не поддерживать этот пиксельный формат; если ffmpeg падает — заменить на
`yuv420p` (альфа в WebM всё равно не сохраняется). Нужна реальная проверка с ffmpeg.
**Критерий:** экспорт WebM проходит реальным ffmpeg; при отсутствии ffmpeg —
понятная ошибка (уже реализована).
