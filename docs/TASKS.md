# Задачи и известные проблемы

Живой список работ. Формат: ID — приоритет — область — описание — критерий готовности.
Приоритеты: **P0** — ломает базовый сценарий/виден сразу, **P1** — заметный дефект,
**P2** — улучшение/гигиена.

После закрытия задачи: перенести в «Сделано» с датой, обновить `ROADMAP.md` при
необходимости.

## P0 — блокеры

### T-002 · «Don't Save» теряет отложенную команду
**Файлы:** `src/dialogs.rs::unsaved_dialog`
**Симптом:** при несохранённых изменениях выбираем New/Open/Exit → диалог → «Don't
Save»: диалог закрывается, но команда не выполняется (`pending` обнуляется).
**Критерий:** после «Don't Save» выполняется исходная команда (создать/открыть/
закрыть), `dirty` сбрасывается корректно.

### T-003 · Закрытие окна ОС не спрашивает о несохранённых изменениях
**Файлы:** `src/app.rs::update`
**Симптом:** крестик окна закрывает приложение без диалога.
**Критерий:** перехват `ViewportCommand::Close` / `ctx.input(|i| i.viewport().close_requested())`,
при `dirty` — диалог, при отмене — `CancelClose` или эквивалент.

## P1 — заметные дефекты

### T-011 · Точки в пустых кадрах
**Файлы:** `src/timeline.rs` (отрисовка `FrameKind::Empty`)
**Симптом:** каждая пустая ячейка рисует полый кружок — визуальный шум.
**Критерий:** точка рисуется только для key/blank key; пустые кадры — только сетка
(по желанию — одна точка в конце спана).

### T-012 · Alt+O не работает, хотя указан в меню
**Файлы:** `src/app.rs::menu_bar` (текст), `src/app.rs::handle_shortcuts`
**Критерий:** `Alt+O` переключает он-скин; подпись в меню соответствует реальности.

### T-013 · Статус-бар хранит сообщение вечно
**Файлы:** `src/app.rs::notify`, `status_bar`
**Симптом:** подсказка «Brush (B)…» остаётся навсегда, перекрывает новые события.
**Критерий:** сообщение гаснет через 4–6 с (использовать `ctx.input(|i| i.time)`),
базовая подсказка инструмента возвращается.

### T-014 · Двойной инкремент `stamps`
**Файлы:** `src/canvas.rs::begin_stroke`, `stamp_dab`
**Симптом:** `stamps` увеличивается и в `stamp_dab`, и в `begin_stroke`.
**Критерий:** счётчик увеличивается ровно один раз на штамп; undo не создаётся для
пустого штриха.

### T-015 · Кэш `blank_cache` не чистится
**Файлы:** `src/app.rs` (`blank_cache`), `src/timeline.rs`
**Симптом:** записи копятся при удалении слоёв/кадров (утечка памяти на больших
проектах).
**Критерий:** при удалении слоя/документа/undo-структуры кэш очищается или фильтруется
по существующим `(uid, frame)`.

### T-016 · Крестик вкладки создаёт новый документ
**Файлы:** `src/app.rs::tab_bar`
**Симптом:** клик по `×` отправляет `Cmd::New`.
**Критерий:** при однодокументном режиме крестик либо закрывает вкладку с диалогом
сохранения, либо скрыт. Не должно быть «создать новый».

## P2 — гигиена и улучшения

### T-020 · Мёртвый код и предупреждения
**Файлы:** `src/ui.rs` (`bar`, `swatch`), `src/icons.rs` (`icon_widget`,
`toggle_icon`), `src/app.rs` (`show_guides`, `Cmd::Cut/Copy`), `src/dialogs.rs`
(`DocSetup::bg_color32`)
**Критерий:** `cargo build` без предупреждений (или осознанно оставленные
`#[allow(dead_code)]` с комментарием).

### T-021 · Неиспользуемые импорты
**Файлы:** `src/canvas.rs` (`Context`), `src/timeline.rs` (`Cmd` в некоторых
местах) — проверить `cargo build`.
**Критерий:** нет warning: unused import.

### T-022 · Быстрый слайдер размера кисти
**Идея:** в тулбаре меню уже есть быстрые инструменты — добавить туда маленький
`DragValue` размера или `[ ]`-подсказку.

### T-023 · Сохранение настроек между запусками
**Идея:** eframe `persistence` (feature `persistence`) для размера окна, последнего
документа, настроек кисти. Требует включить фичу и реализовать `App::save`.

### T-024 · Импорт изображений
**Идея:** File → Import → PNG/JPEG на текущий keyframe. Нужен декодер (`png` уже
есть; JPEG — отдельный крейт или `image` с `--no-default-features` + `jpeg`).

### T-025 · Прозрачность и режимы слоя
**Идея:** `Layer.opacity`, `Layer.blend`. Для blend-режимов нужен CPU-композит или
шейдер (сейчас GPU-композит с Normal).

### T-026 · Мультивыделение кадров
**Идея:** drag-рамка по сетке, `Shift`/`Ctrl`, групповые F5/F6/удаление. Требует
переработать `sel_frame` в `selection: (layer, RangeInclusive<usize>)`.

### T-027 · Превью в диалоге открытия
**Идея:** показывать первый кадр/размер/fps проекта до открытия.
