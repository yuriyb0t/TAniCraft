# Формат файла `.tcraft`

Один проект = один файл. Внутри: текстовый манифест (JSON) и PNG-данные каждого
ключевого кадра. Формат читается/пишется в `src/doc.rs`
(`save_document` / `load_document`).

---

## 1. Бинарная раскладка

Все целые — little-endian.

| Смещение | Размер | Поле |
|---|---|---|
| 0 | 8 | magic: ASCII `TACRAFT1` |
| 8 | 4 | `u32` — длина JSON в байтах |
| 12 | N | JSON-манифест (UTF-8) |
| 12+N | 4 | `u32` — длина PNG №0 |
| … | M | PNG №0 |
| … | 4 | `u32` — длина PNG №1 |
| … | M | PNG №1 |
| … | — | … до конца файла |

Блоки изображений идут подряд без выравнивания. Количество блоков определяется
чтением до EOF; индексы из манифеста ссылаются на порядок блоков (0-based).

Ограничения при чтении:

- magic обязателен, иначе ошибка «not a TAniCraft project»;
- JSON ограничен 64 МиБ (защита от повреждённых файлов);
- `version` больше `FILE_VERSION` → отказ с просьбой обновить приложение;
- лишние/недостающие блоки изображений не фатальны: отсутствующая картинка
  заменяется пустым кадром.

## 2. Манифест JSON

```json
{
  "version": 1,
  "name": "Untitled-1",
  "width": 1280,
  "height": 720,
  "fps": 24.0,
  "bg": [255, 255, 255, 255],
  "layers": [
    {
      "name": "Layer 1",
      "visible": true,
      "locked": false,
      "frames": [
        { "kind": 2, "image": 0 },
        { "kind": 1, "image": null },
        { "kind": 2, "image": 1 },
        { "kind": 0, "image": null }
      ]
    }
  ]
}
```

### Поля

| Поле | Тип | Смысл |
|---|---|---|
| `version` | u32 | версия формата (сейчас `1`) |
| `name` | string | имя документа (без расширения) |
| `width`, `height` | u32 | размер холста в пикселях, ≥ 1 |
| `fps` | f32 | кадровая частота, 1..120 |
| `bg` | [u8;4] | фон **в straight alpha** (R,G,B,A) |
| `layers[]` | array | слои снизу вверх (индекс 0 — нижний) |
| `name` | string | имя слоя |
| `visible` | bool | видимость |
| `locked` | bool | блокировка редактирования |
| `frames[]` | array | кадры слоя, индекс = номер кадра |
| `kind` | u8 | `0` = Empty, `1` = Hold, `2` = Key |
| `image` | u32? | индекс PNG-блока для `Key`, иначе `null` |

Ключевые кадры без блока изображения (`"image": null`, `kind: 2`) допустимы — при
загрузке создаётся пустой битмап.

### Размеры изображений

PNG должны быть ровно `width × height` документа. Загрузчик **не** проверяет это:
картинка берётся как есть и растягивается на прямоугольник документа при отрисовке.
Если меняете размер холста, используйте `Document::resize_canvas` (пересоздаёт все
битмапы) — иначе файл может получиться с «чужими» размерами.

## 3. Пиксельный формат

| Где | Формат |
|---|---|
| В памяти (`Bitmap`) | premultiplied RGBA8 |
| В PNG (файл) | straight (unpremultiplied) RGBA8, `ColorType::Rgba`, `BitDepth::Eight` |
| В `ColorImage` (egui) | premultiplied RGBA8 |

Конвертация: `Bitmap::to_rgba_straight()` при записи,
`Bitmap::from_rgba_straight()` при чтении. При альфе 0 RGB обнуляется, при
`0 < a < 255` каналы делятся на альфу.

Загрузчик также понимает PNG `RGB8` и `Grayscale8` (альфа = 255), остальные
варианты отклоняются с ошибкой.

## 4. Правила версионирования

1. `FILE_VERSION` (`doc.rs`) повышается при **несовместимом** изменении.
2. Совместимые добавления — новые поля с `#[serde(default)]`; старые файлы
   читаются без ошибок, `version` можно не менять.
3. Никогда не перенумеровывать `kind` (0/1/2) — это сломает старые проекты.
4. Удаление поля — только с повышением версии и миграцией.
5. При повышении версии: обновить этот файл, `README.md` и добавить запись в
   `DECISIONS.md`.

## 5. Ограничения текущего формата

- Нет превью/миниатюры проекта.
- Нет символов, твинов, звука, текста — только растровые кадры.
- Нет дедупликации одинаковых изображений (один ключевой кадр = один PNG).
- Нет сжатия манифеста (JSON пишется как есть).
- Нет контрольной суммы: повреждённый PNG вызовет ошибку загрузки всего файла.

## 6. Быстрая проверка файла

```powershell
# magic + длина JSON
$b = [IO.File]::ReadAllBytes("project.tcraft")
[Text.Encoding]::ASCII.GetString($b[0..7])          # TACRAFT1
[BitConverter]::ToUInt32($b, 8)                     # длина JSON
# сам JSON
$len = [BitConverter]::ToUInt32($b, 8)
[Text.Encoding]::UTF8.GetString($b[12..(11 + $len)])
```

Ожидаемый результат: `TACRAFT1`, разумная длина JSON (сотни байт), читаемый JSON
с полями из раздела 2.
