# UI-гайд

Цель интерфейса — визуально и поведенчески напоминать Adobe Animate: тёмные панели,
компактные иконки, таймлайн внизу, инструменты справа, свойства справа сверху,
холст по центру. Этот файл фиксирует геометрию, цвета и правила, чтобы новые фичи
не разъезжались по стилю.

---

## 4. Иконки

- Все иконки — векторные, `src/icons.rs`, `Icon::*` + `icons::paint(painter, rect, icon, color)`.
- Рисуются в нормализованных координатах 0..1, толщина штриха ~1.1–1.8 px.
- Размер: 24×24 в тулбарах (иконка внутри ~14 px), 16–18 px в списках слоёв.
- Активная иконка — белая, неактивная — `TEXT`, недоступная — `TEXT_FAINT`.
- Новую иконку добавлять в `enum Icon` и в `match` внутри `paint`; внешние SVG/PNG
  не использовать.

## 5. Панели

### Меню-бар
`File Edit View Insert Modify Control Window Help` + быстрые инструменты
(Brush/Eraser/Eyedropper/Hand/Zoom) + справа «Workspace / Essentials ▾».
Пункты меню дублируют горячие клавиши текстом (`Save Ctrl+S`).

### Вкладка документа
Одна вкладка (однодокументное приложение): имя + `*` при изменениях, крестик,
кнопка `+`. Справа — `W × H  fps`.

### Tools (слева, 62 px)
Сетка 2×N: Selection, Transform, Lasso, Pen, Pencil, Brush, Eraser, Bucket,
Eyedropper, Text, Hand, Zoom. Ниже — чипы fill/stroke, swap и «default colors».
Недоступные инструменты показываются, но отключены (tooltip «not yet available»).
Пипетка (`I`) берёт цвет с композитного холста; Alt+ЛКМ делает то же с Brush/Eraser.

### Properties (справа сверху)
Секции сверху вниз: `TOOL`, `FRAME`, `LAYER`, `DOCUMENT`. Каждая — заголовок
`ui::section_title` + содержимое. Слайдеры — `ui::slider_row` (лейбл 72 px,
значение справа). Кнопки операций с кадром — F6/F7/F5/Clear.

### Timeline (внизу)
Тулбар: транспорт, счётчик кадров, fps, операции с кадрами, он-скин, имя слоя.
Тело: фиксированная колонка слоёв (208 px) + сетка кадров + линейка + плейхед.
Высота панели изменяется перетаскиванием верхней границы и сохраняется между кадрами.
Строки слоёв: `eye` (12 px), `lock` (30 px), имя (с 42 px). Выделенный слой —
фон `#3b3b3b` и акцентная полоса слева.

### Статус-бар
Слева подсказка/последнее действие (`App::notify`); сообщение гаснет через 5 с и
сменяется подсказкой активного инструмента. Справа — инструмент, кадр, зум.

## 7. Диалоги

- Модальные (`New Document`, `Save changes?`) — `egui::Modal`, затемнение фона,
  кнопки справа: `Cancel` и основная (`Create`/`Save`).
- Свойства (`Document Properties`, `Layer Properties`, `About`, `Fill Colour`) —
  `egui::Window` с `.anchor(CENTER_CENTER)`, без resize, стиль `ui::panel_frame`.
- Ширина: новый документ 360 px, свойства документа 330 px, слой 280 px.
- Поля — `egui::Grid` с двумя колонками (лейбл 11 px `TEXT_DIM`, контрол).
- Никаких «голых» системных окон: всё внутри egui.

## 8. Известные отклонения (исправить)

1. Пустые кадры рисуют точку в каждой ячейке — точка нужна только в конце спана
   (или не нужна вовсе).
2. Tools: иконки стоят слишком плотно к краю — проверить отступы после правок.

Исправлено 2026-10-29: обрезанный меню-бар и наезжающие чекбоксы Visible/Locked.
Причина была не в вёрстке, а в системной светлой теме egui; `theme::apply` теперь
принудительно включает тёмную тему. Если виджеты снова стали светлыми — смотреть
`theme.rs::apply`, а не панели.

## 9. Чек-лист визуальной проверки

- [ ] Меню читается целиком, пункты не обрезаны.
- [ ] Панели не перекрывают друг друга, таймлайн на всю ширину.
- [ ] Активный инструмент подсвечен акцентом, курсор соответствует инструменту.
- [ ] На таймлайне различимы key / hold / blank key / empty.
- [ ] Плейхед виден на линейке и в сетке, номер кадра обновляется.
- [ ] Диалоги центрированы, кнопки справа, Esc/крестик закрывают.
- [ ] Текст не выходит за границы панелей при 1040×680 (минимальный размер окна).
