# Изображения документации

Сюда кладутся **только** скриншоты и схемы для документации. Приложение не читает
эту папку: по правилу проекта (`AGENTS.md`) внешних ассетов, шрифтов и иконок в
сборке нет — иконки рисуются вектором в `src/icons.rs`.

## Правила

- Имена: `ui-main.png`, `ui-timeline.png`, `ui-properties.png`, `ui-dialog-new.png`.
- Формат — PNG, ширина 1200–1600 px (не больше 2 МБ на файл).
- Скриншот снимается `scripts\screenshot.ps1`, при необходимости обрезается.
- Перед коммитом проверить, что на картинке нет личных путей и имён файлов.
- Локальные скриншоты для отладки складывать в `shots\` (в `.gitignore`), а не сюда.

## Как вставить в документ

```markdown
![Главное окно](images/ui-main.png)
```
